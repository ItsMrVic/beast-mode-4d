2 · Historical prediction evaluation

Predictions recorded before the target calendar day are pre-day verifiable. Same-day entries are evaluated provisionally because the backup does not establish a draw cutoff. Permutations are observations, not confirmed ticket wins. Cross-operator results are shown separately. The random expectation assumes independent uniformly random four-digit outcomes; real draw rules may differ.

Import a backup to calculate the results.

3 · Match explorer

Inspect the actual predicted and drawn numbers. Matches are categorized by operator and prize tier. A prediction matching more than one operator is counted once in each relevant category, never as a confirmed paid ticket.

Import a backup first.

4 · Consensus study

Counts how often different modes independently proposed the same four-digit number for the same operator and target date. Consensus does not imply increased probability.

Import a backup first.
