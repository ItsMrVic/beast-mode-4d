3 · How the Scores Are Calculated

Exact match (straight) means all four digits match in exactly the same order. Permutation / box means the same digits appear in a different order; this is not a winning Big straight ticket. A result from another operator does not count as a win on an operator where no ticket was purchased.

Big (RM1 per number) uses RM3,500 / RM1,200 / RM600 for 1st / 2nd / 3rd, RM250 for Special and RM80 for Consolation. Small (RM1 per number) uses editable top-three payouts of RM5,000 / RM2,400 / RM1,200; it pays nothing on Special or Consolation. The new 4A / 4B / 4C / 4E tabs use your BK8 screenshot at RM1 per number per chosen bet type: 4A pays RM8,000 on 1st only, 4B RM8,000 on 2nd only, 4C RM8,000 on 3rd only, and 4E RM800 for each exact Consolation win (10 prize positions). 4E does not cover Special. Each bet type has its own independent stake. All four combined costs RM4 per number. Figures are gross before stakes are deducted; this is a simulation, not a verified bet receipt.

Large spending is not recommended: historical BEAST MODE tests have not demonstrated a reliable advantage over random selection.
