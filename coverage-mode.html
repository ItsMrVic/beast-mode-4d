3 · How the Scores Are Calculated

Exact match (straight) means all four digits match in exactly the same order. Permutation / box means the same digits appear in a different order; this is not a winning Big straight ticket. A result from another operator does not count as a win on an operator where no ticket was purchased.

Big (RM1 per number) uses reference payouts of RM3,500 / RM1,200 / RM600 for 1st / 2nd / 3rd, RM250 for each Special and RM80 for each Consolation. Small (RM1 per number) pays only the top 3 exact matches; the editable default rates are RM5,000 / RM2,400 / RM1,200. Special and Consolation pay RM0 on Small. The table compares separate Big-only, Small-only, and Big + Small scenarios per operator. Big + Small costs RM2 per selected number. The displayed gross payouts and nets are simulated, not actual purchased tickets or confirmed BK8 payout rates.

Large spending is not recommended: historical BEAST MODE tests have not demonstrated a reliable advantage over random selection. At RM1 per number per bet type, the complete 10,000-number set costs RM10,000 for Big alone, RM10,000 for Small alone, or RM20,000 for both per operator. With the current illustrative payout rates, the maximum gross payout is RM8,600 for either Big or Small, leaving a simulated RM1,400 loss for each bet type.

Original base sets date from 2026-11-14; the 370 repeated-digit combinations and the last 130 omitted combinations were added to all five sets on 2026-11-15.
