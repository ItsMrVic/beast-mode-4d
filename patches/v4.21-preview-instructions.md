# v4.21 preview fixes (not yet deployed)

The audited v4.20 source is a 2 MB single-file app. A tested local v4.21 preview was prepared from the user's uploaded HTML; the full HTML could not be transferred back through the GitHub connector because of file-size limitations. This branch documents the exact intended edits and preserves `main`.

## Edit 1 — Operator filtering
Replace `historyMatchesOperator` with:

```js
function historyMatchesOperator(entry,operator){
  if(operator==='all')return true;
  if(operator==='UNASSIGNED')return !historyEntryTargetOperator(entry);
  return historyEntryTargetOperator(entry)===operator;
}
```

Add this option to the History prediction-operator select:

```html
<option value="UNASSIGNED"${histOperator==='UNASSIGNED'?' selected':''}>Cross-operator / unassigned</option>
```

## Edit 3 — Restore settings from backups
Replace the line resetting weights and toggles in `importData()` with:

```js
const validPlainObject=v=>v&&typeof v==='object'&&!Array.isArray(v);
const own=(obj,k)=>Object.prototype.hasOwnProperty.call(obj,k);
moduleWeights=validPlainObject(data.moduleWeights)
  ?{...DEFAULT_WEIGHTS,...Object.fromEntries(Object.entries(data.moduleWeights).filter(([k,v])=>own(DEFAULT_WEIGHTS,k)&&Number.isFinite(v)&&v>=0))}
  :{...DEFAULT_WEIGHTS};
moduleToggles=validPlainObject(data.moduleToggles)
  ?{...DEFAULT_TOGGLES,...Object.fromEntries(Object.entries(data.moduleToggles).filter(([k,v])=>own(DEFAULT_TOGGLES,k)&&typeof v==='boolean'))}
  :{...DEFAULT_TOGGLES};
moduleTogglesPerOp={};
if(validPlainObject(data.moduleTogglesPerOp))for(const op of ['MAGNUM','TOTO','DAMACAI']){
  if(validPlainObject(data.moduleTogglesPerOp[op]))
    moduleTogglesPerOp[op]={...moduleToggles,...Object.fromEntries(Object.entries(data.moduleTogglesPerOp[op]).filter(([k,v])=>own(DEFAULT_TOGGLES,k)&&typeof v==='boolean'))};
}
```
